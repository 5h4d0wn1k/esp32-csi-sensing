# Physical photos (shot list)

Photos go in this directory. Keep every shot tight on hardware: no faces,
no street-facing windows, no mail/documents, nothing that identifies the
home. See docs/PRIVACY.md before committing images.

| File | What must be visible | Framing |
|------|----------------------|---------|
| `receiver-front.jpg` | NodeMCU receiver, USB cable, antenna area | top-down, board fills frame |
| `receiver-back.jpg` | same board flipped (pin labels visible) | top-down |
| `sender.jpg` | ESP32-C6 sender board | top-down |
| `router.jpg` | the AP/router unit | front, LEDs visible; no ISP stickers |
| `oled-wired-1.jpg` | OLED wired to receiver, both boards in frame | 45-degree angle |
| `oled-wired-2.jpg` | close-up of the 4 (or 6) jumper connections | macro, labels readable |
| `bench-overview.jpg` | full demo bench: laptop + hub + both nodes | wide shot, screen showing viewer |
| `room-layout.jpg` | hand-drawn top-down sketch of node/router placement | scan or photo of paper sketch |

Conventions:

- JPEG or PNG, longest side ~1600 px is plenty.
- Filenames exactly as above so README/docs links stay stable.
- If a photo accidentally shows something identifying, delete it before
  staging - do not rely on later fixes.
